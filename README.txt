MAISON DIMS — WEBSITE PROJECT

FILES
- index.html: homepage
- products.html: product catalogue
- product-detail.html: product detail page
- style.css: website styling
- images/: campaign and lookbook images

IMPORTANT
Keep style.css and the images folder in the same project folder as the HTML files.
Do not open index.html from inside the ZIP preview. Extract the ZIP first.

ANDROID
1. Extract MAISON-DIMS-project.zip using Files/File Manager.
2. Open Acode (or another code editor that supports project folders).
3. Open the extracted fashion-store folder as a project.
4. Open index.html and use the editor's Preview option.
If you open the HTML directly from a file manager's built-in preview, Android may block access to neighboring CSS/image files. That is why the page can look unstyled.

MAC / WINDOWS
1. Extract the ZIP.
2. Open the fashion-store folder in VS Code.
3. Open index.html with Live Server (or use another local web server).
