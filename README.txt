MAISON DIMS — WEBSITE PROJECT

Cara memasang ke GitHub:
1. Ekstrak ZIP ini.
2. Unggah/replace file index.html, products.html, product-detail.html, style.css, serta semua foto JPG/PNG ke root repository GitHub Pages.
3. Commit changes dan tunggu GitHub Pages selesai deploy.
4. Buka products.html lalu tekan salah satu produk. Setiap produk yang sudah memiliki foto akan membuka halaman detail dengan tiga foto berbeda.

Catatan foto:
- Delapan set foto produk lengkap tersedia di ZIP ini (depan, belakang, label/ukuran).
- Katalog menampilkan sembilan slot. Slot ke-9 sengaja ditandai "Produk Baru / Foto Menyusul" karena ZIP sumber belum berisi tiga foto unik untuk produk ke-9. Tambahkan tiga file foto produk itu sebelum mengaktifkannya.
- Nama file harus sama persis, termasuk huruf besar/kecil, dengan nama yang digunakan di HTML.
